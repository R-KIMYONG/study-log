# 2026-09-15 Vue 기본기 (React 개발자용)

## 🛠️ 세팅
- 생성: `yarn create vue`(또는 `npm create vue@latest`) → 최소 구성(전부 No) + TypeScript Yes
- **Node 22+ 필수** (create-vue 최신). nvm이면 `nvm use 22` + **`nvm alias default 22`**(새 터미널도 기본 22)
- VSCode 확장: **"Vue - Official"**(구 Volar) — .vue 색·자동완성. (Vetur ❌ 옛날 거)
- Emmet 안 되면: settings.json `"emmet.includeLanguages": { "vue": "html" }`, `div`+**Tab**
- Tailwind(Vite): `yarn add tailwindcss @tailwindcss/vite` → vite.config에 `tailwindcss()` → main.css에 `@import "tailwindcss";`
- 실행: `yarn dev` → localhost:5173

## 📄 SFC 구조 (.vue = 3블록)
```vue
<script setup lang="ts">   <!-- 로직 (React 함수 본문 자리) -->
import { ref } from 'vue'
const count = ref(0)
</script>

<template>                 <!-- 화면 (return JSX 자리) -->
  <button @click="count++">{{ count }}</button>
</template>

<style scoped>             <!-- 이 컴포넌트에만 적용 (내장) -->
button { color: teal; }
</style>
